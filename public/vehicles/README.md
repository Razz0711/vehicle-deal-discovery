# Vehicle photographs

Put real, licensed photographs here and register each one in
`src/data/vehiclePhotos.ts`. Until a slot is registered the site shows a
neutral "Photograph to be added" frame for it.

| File | Must show |
|---|---|
| car.jpg | a production car |
| bike.jpg | a motorcycle |
| scooter.jpg | a petrol scooter |
| ev.jpg | an electric car |
| ev-scooter.jpg | an electric scooter |
| truck.jpg | a commercial vehicle |

Landscape, 3:2 or wider, at least 1600 px wide, vehicle roughly centred.
Model-specific photographs go in `models/` (for example `hyundai-creta.jpg`).
No illustrations, renders or AI-generated images.
